Client Drive Folder Map

The one structure every client folder follows — so anyone on the team can find, file, and hand over work without guessing. Set it up the same way, every time.

HOME FOLDER› [CLIENT NAME]› [YEAR]› [YEAR] [CLIENT NAME] – SHARED [CLIENT NAME] – INTERNAL

How to read this

Each client gets two top folders inside their year folder. Build both to match this map exactly.

SHARED — client can see INTERNAL — team only

Placeholders

Anything in [BRACKETS] is a name you fill in — swap it for the real client, month, event or name.

File naming — always

Date first, then client, then type: DD-MM-YY_Client Name_Type. Use the actual month name for month folders. Coloured notes below are non-negotiable.
